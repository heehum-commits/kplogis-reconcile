# 실적 대조 시스템 — 경평물류(주)

담당자가 직접 정리해 보내준 실적과 TMS 전산 내역을 맞춰보고,
**빠진 건 · 금액이 다른 건 · 누가 틀렸는지**를 뽑아내는 도구입니다.

설치가 필요 없습니다. `index.html` 파일 하나를 브라우저로 열면 바로 씁니다.
서버도, 데이터베이스도 없습니다.

👉 **바로 열기 → https://heehum-commits.github.io/kplogis-reconcile/**

## 쓰는 법

1. 엑셀에서 표 전체를 복사(Ctrl+A → Ctrl+C)해서 왼쪽 칸(담당자 자가 진행분)에 붙여넣기
2. TMS에서 같은 기간으로 내려받은 내역을 오른쪽 칸에 붙여넣기
3. **[대조 실행하기]**

처음이라면 **[🧪 예시 데이터로 먼저 해보기]** 를 눌러 한 번 돌려보세요.
(예시 데이터는 전부 가상 숫자입니다.)

첫 줄은 반드시 제목 줄이어야 합니다. 제목 이름은 아래처럼 섞여 있어도 알아서 찾습니다.

| 항목 | 알아듣는 제목 |
|---|---|

| 오더번호 | 오더번호, 오더, 관리번호, 배차번호, 운송번호, 접수번호 |

| 차량번호 | 차량번호, 차량, 차번, 배차차량 |

## 결과는 5가지로 갈라집니다

| 표시 | 뜻 | 할 일 |
|---|---|---|
| ✅ 일치 | 양쪽 다 있고 금액도 같음 | 볼 필요 없음 |
| ⚠️ 차이·중복 | 금액이 다르거나, 같은 건이 두 번 있거나, 일자가 하루 다름 | 어느 쪽이 맞는지 확인 |
| 🟡 TMS 누락 | 담당자분에만 있음 | 전산 입력이 안 된 건 |
| 🔴 보고 누락 | TMS에만 있음 | 담당자가 빠뜨린 건 |
| 🔵 기간 밖 | 두 자료가 겹치지 않는 날짜 | 오류 아님 (일치율에서 제외) |

## 짝은 어떤 순서로 맞추나요

1. **오더번호** — 양쪽에 다 있는 건끼리 먼저
2. **일자 + 차량번호** — 남은 건. 차량번호는 `부산80바1234` 와 `80바1234` 를 같은 차로 봅니다
3. **일자 하루 차이 + 차량번호** — 담당자는 상차일, TMS는 완료일로 적어 하루 밀린 건을 찾습니다.
   이렇게 찾은 건은 자동으로 일치 처리하지 않고 **항상 ⚠️ 로 올려** 사람이 판단하게 합니다

끝까지 짝이 없는 건만 한쪽에만 있는 것(🟡 · 🔴)으로 봅니다.
그 중 **청구금액이 똑같은 쌍**이 있으면 "짝 후보 있음"으로 서로를 가리켜 줍니다.

엑셀 맨 아래 **합계 · 소계 줄은 자동으로 빼고** 읽습니다.
금액 `(50,000)` · `△50,000` 은 마이너스로, 날짜가 숫자 `45905` 로 복사돼도 날짜로 읽습니다.

### 조절할 수 있는 것

- **금액 허용 오차** — 원단위 절사·부가세 처리로 생기는 잔돈 차이를 걸러냅니다 (기본 0원)
- **일자 하루 차이 허용** — 위 3차 매칭을 켜고 끕니다
- **대조 기간 밖 건 분리** — 두 자료의 겹치는 기간만 일치율에 넣습니다

## 제미나이 AI 기능 (선택)

대조가 끝나면 맨 아래에서 AI에게 세 가지를 시킬 수 있습니다.

- 📄 요약 보고문 — 팀장께 올릴 보고 초안
- ✉️ 담당자 확인 요청 문구 — 담당자별로 나눠서
- 🔍 차이 원인 추정 — 상차일/완료일 차이, 오더번호 미기재, 중복 입력 등

**API 키가 필요합니다.** https://aistudio.google.com/apikey 에서 무료로 발급받아 화면에 붙여넣으세요.

> ⚠️ **이 기능을 쓰면 대조 내용(화주명·담당자명·금액)이 구글 서버로 전송됩니다.**
> **[👁 보낼 내용 미리보기]** 로 무엇이 나가는지 먼저 확인하고, 회사 방침을 확인한 뒤 사용하세요.
> 버튼을 누르기 전에는 아무것도 나가지 않습니다.

키는 **사용하는 PC의 브라우저에만** 저장되고 이 저장소 코드에는 들어 있지 않습니다.
키를 저장소에 올리거나 남에게 공유하지 마세요.

동작을 확인한 모델: `gemini-3.6-flash`(기본), `gemini-3.5-flash`, `gemini-3-flash-preview`, `gemini-3.1-flash-lite`

## 만든 배경

장금상선 그룹 AI Agent 교육(부산 1회차) 모듈1 개인 프로젝트로 시작했습니다.
워크시트에서 고른 과제 "실적관리 시스템"을 그대로 **입력 → 처리 → 출력 → 평가** 4단계로 만들었습니다.

- 입력 — 담당자 자가 진행분
- 처리 — TMS 전산과 대조
- 출력 — 확인이 필요한 건 목록 + 엑셀(CSV) 저장
- 평가 — 일치율, 담당자별 정확도
